Understanding C Arrays

A beginner-friendly visual guide to 1D arrays, 2D arrays, strings, 2D character arrays, stacks and the pointer approach in C.

char valStack[50][100];

1. What is an Array?

An array is a collection of elements of the same data type.

One Variable

Normally, one variable stores one value.

int x = 10;

Array

An array lets us store many values under one variable name.

int arr[5];

A 2D array is like a table containing rows and columns.

int arr[3][4];

3 rows × 4 columns

Total elements: 3 × 4 = 12

The second index represents the column.

So: arr[2][3] means: row 2, column 3.

3. 2D Character Array

This is where 2D arrays become very useful for storing multiple strings.

char arr[3][100];

You can think of this as:

3 strings
Each string can contain up to 99 characters plus \0.
arr[0]
"HELLO"
arr[1]
"WORLD"
arr[2]
"APPLE"

Character-by-character

arr[1] = "WORLD"

arr[1][0] → 'W'
arr[1][1] → 'O'
arr[1][2] → 'R'
arr[1][3] → 'L'
arr[1][4] → 'D'
arr[1][5] → '\0'
Remember:

arr[1] means the entire string.
arr[1][2] means one character.

4. Why Does valStack Use 2D Array?

This is exactly what happens in your infix-to-prefix program.

char valStack[50][100];
Think of this as:

50 stack positions
where each position can store an entire string.
A
B
*BC
+A*BC ← TOP
Value Stack
valStack[0] → "A"
valStack[1] → "B"
valStack[2] → "*BC"
valStack[3] → "+A*BC"

This is useful because during prefix conversion, a stack element may be more than one character.

"5"
"3"
"*34"
"+5*34"

5. arr[2] vs arr[2][0]

This distinction is extremely important.

char arr[3][100];

arr[2] = "*BC"

arr[2][0] = '*'
arr[2][1] = 'B'
arr[2][2] = 'C'
arr[2][3] = '\0';

arr[2]

Represents the entire string.

"*BC"

arr[2][0]

Represents the first character.

'*'

6. Understanding char*

Why does popVal() return char* instead of char?

char* popVal() { return valStack[valTop--]; }

Suppose the stack contains:

valStack[2] = "*BC";
valStack[2]
↓
"*BC"

popVal() → address of the first character
Important:

popVal() technically returns an address.

When that address is used as a string, C can access the characters starting from that address until it reaches \0.

Why not char?

char popVal();

This could return only one character:

'A'

But our stack may contain:

"*BC"

Therefore we use:

char* popVal();

7. Understanding strcpy()

strcpy(v2, popVal());

Remember:

strcpy(destination, source);

So:

strcpy(v2, popVal());
popVal() → address of "*BC"

"*BC" → strcpy() → v2

v2 = "*BC"

8. Why popVal() and popOp() are Different

Stack Declaration Contains Return Type
Operator Stack char opStack[50] +, *, - char
Value Stack char valStack[50][100] "A", "*BC" char*
char popOp() { return opStack[opTop--]; }

char* popVal() { return valStack[valTop--]; }

9. Connecting It to Infix → Prefix

Suppose the expression is:

A + B

The stacks contain:

Value Stack:
A
B ← TOP

Operator Stack:
+ ← TOP

First:

strcpy(v2, popVal());

Therefore:

v2 = "B"

Then:

strcpy(v1, popVal());

Therefore:

v1 = "A"

Operator:

op = popOp(); op = '+';

Finally:

sprintf(result, "%c%s%s", op, v1, v2);
result = "+AB"

10. Prefix vs Postfix

Notation Order A + B
Infix left → operator → right A+B
Prefix operator → left → right +AB
Postfix left → right → operator AB+
// PREFIX sprintf(result, "%c%s%s", op, v1, v2); // POSTFIX sprintf(result, "%s%s%c", v1, v2, op);
